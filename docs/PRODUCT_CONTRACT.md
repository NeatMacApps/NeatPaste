# 产品契约

改、评审或排查 NeatPaste 的用户可见行为前必读。这里是体验与范围的唯一权威源；代码必须服从本文，而不是反过来。

## 产品是什么

NeatPaste 是 macOS 26+ 的菜单栏剪贴板历史工具。复制之后可以用全局快捷键或菜单栏图标唤出面板，按时间从新到旧挑选一条，回车粘贴回刚才正在输入的应用。

它和 App Store 上那款同名 iOS「文本清理」应用不是同一个产品，也不存在关系。

## 钉死的体验

这些默认行为不允许改成「可选项」或「后续再说」：

| 行为 | 契约 |
|---|---|
| 打开面板 | 列表纯时间序，**默认选中第一条（最新）** |
| 回车 | 把当前选中项交给粘贴引擎，然后关掉面板（若还不能自动按粘贴键，则留在面板里提示去打开辅助功能） |
| 历史保留 | **7 天**，按 `7 * 24 * 3600` 秒计算，到期清除 |
| 探测间隔 | **0.5 秒**查看系统剪贴板是否变化 |
| 面板位置 | 尽量锚在当前输入光标附近；失败则退到鼠标所在屏幕、光标附近；再失败则该屏幕可见区域中心偏上。多屏和全屏都必须夹紧在可见区域内 |
| 行高 | 文本和图片同一固定行高；图片位置用固定小方图占位 |
| 格式 | **不降级**：有图片就按图片占位/展示，有文本就保留文本，不得为了实现方便把内容改写成另一种格式 |
| 焦点 | 打开面板时**不得**把 NeatPaste 变成前台应用，否则粘贴会贴到自己身上 |
| 快捷键默认值 | ⌘⇧V，可在设置里改 |
| 开机自启 | 提供开关，**默认关闭** |

## 明确不做

第一波和后续默认都不做，除非产品重新拍板：

- 钉住 / 收藏
- 云同步、多设备、账号
- AI 整理、分类、改写
- 跨平台（Windows / Linux / iOS / Web）
- Mac App Store 版
- 把富文本、图片或文件降成纯文本来「凑合能搜」

## 第一波范围

第一波必须能：编译、装进「应用程序」、菜单栏出现图标、快捷键或点击图标唤出面板、Esc 关闭、⌘, 打开设置、列表展示 3 条假历史、回车走到粘贴接口。

第一波可以：历史用内存假数据；剪贴板监听只留骨架；粘贴在没有辅助功能授权时只写入系统剪贴板并提示。

第一波不要：Sparkle、GRDB、第三方热键库、网络库、SwiftData / Core Data。

## 权限降级

自动按粘贴键需要辅助功能授权。用户拒绝后，应用仍必须能把选中项写入系统剪贴板，并在面板里说明「需要到系统设置里打开，才能自动粘贴」。不得把整段功能锁死。

## 视觉

浮在桌面上的窗口边缘在 macOS 26 可以用玻璃；**列表和预览是内容，必须实底或标准材质**，文字永远在干净底上。去掉系统默认蓝色焦点框，改用与界面一致的自有选中态。
