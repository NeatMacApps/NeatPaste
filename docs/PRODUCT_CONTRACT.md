# 产品契约

改、评审或排查 NeatPaste 的用户可见行为前必读。这里是体验与范围的唯一权威源；代码必须服从本文，而不是反过来。

## 产品是什么

NeatPaste 是 macOS 26+ 的菜单栏剪贴板历史工具。复制之后可以用全局快捷键或菜单栏图标唤出面板，按时间从新到旧挑选一条，回车粘贴回刚才正在输入的应用。

它和 App Store 上那款同名 iOS「文本清理」应用不是同一个产品，也不存在关系。

## 钉死的体验

这些默认行为不允许改成「可选项」或「后续再说」：

| 行为 | 契约 |
|---|---|
| 打开面板 | 列表纯时间序，**默认选中第一条（最新）** |
| 回车 | 把当前选中项交给粘贴引擎，然后关掉面板（若还不能自动按粘贴键，则留在面板里提示去打开辅助功能） |
| 鼠标点选 | 点未选中的条目只选中；**再点已选中的，或双击，等同回车粘贴** |
| 列表右键删除 | 在历史条目上右键弹出菜单，提供「删除」。点后**立刻从本机历史去掉该条**（含磁盘），**不弹确认**。删完后选中仍留在列表里合理的下一条（优先同位置，没有则上一条）；列表空则清空选中。不关面板。不提供清空全部 |
| 历史保留 | **7 天**，按 `7 * 24 * 3600` 秒计算。存在本机，**重启、退出后再打开都还在**；到期清除。不是只在本次运行里记着 |
| 探测间隔 | **0.5 秒**查看系统剪贴板是否变化。有的应用会先改变化计数、内容稍后再装上：内容没读到时必须下次再试，不能把这次变化当成已经处理完。0.5 秒内连复制两条，只保留后一条 |
| 面板位置 | 每次打开都尽量锚在**当前输入光标**附近。拿不到光标则退到当前输入框；输入框过大（整页编辑器）则按光标/鼠标所在点，不能按整框底边摆。再失败则鼠标所在屏幕、鼠标附近；再失败则该屏幕可见区域中心偏上。多屏和全屏都必须夹紧在可见区域内。历史面板不记忆上次位置。**快捷键唤出**才保证贴着输入位置；点菜单栏图标时系统往往已丢掉光标，退到鼠标附近是预期 |
| 行高 | 文本和图片同一固定行高；图片在固定小方图里显示**真实缩略图**，不得用通用图标代替 |
| 列表标题 | 图片没有可读正文时显示「图片」；不要把系统临时文件名、内部编号亮给用户。截图保存名这类真人能认的文件名可以显示 |
| 预览 | **空格**唤出系统 Quick Look（与访达同一套预览窗），再按空格关掉预览、Esc 关掉整块面板。必须是小窗，不得占大半屏。预览开着换条目时，预览窗不得忽大忽小、也不得停在大尺寸。窗口标题是「预览」，不是条目正文。面板里**不做常驻预览栏** |
| 格式 | **不降级**：有图片就按图片占位/展示，有文本就保留文本，不得为了实现方便把内容改写成另一种格式。磁盘仍保留收录到的全部可用格式；**完整图片字节不常驻内存**，列表只靠缩略图，空格预览与回车粘贴时再按需读完整载荷。禁止为了省内存把图片改成「只留一种格式再派生」。若多种类型名对应同一份字节（如新旧 TIFF 名），磁盘只存一份、粘贴仍按原类型名写回 |
| 去重 | **相同内容只留一条**。再复制一次已有内容，把这条顶到最上并刷新为最新一次，不得并排出现多条重复。图片去重用收录时算好的内容指纹，不得为了比对把整图留在内存列表里 |
| 焦点 | 打开面板时**不得**把 NeatPaste 变成前台应用，否则粘贴会贴到自己身上。**恢复窗口是普通带标题栏窗口，可以激活**；不要把「面板不抢前台」套到恢复窗口上，也不要把恢复窗口的激活套到历史面板上 |
| 关闭面板 | **点面板外任意位置立刻关掉**（含点回正在用的应用、桌面、别的窗口），不要继续挡屏幕。Esc、粘贴成功同样关掉。点菜单栏本图标仍走开关；点系统预览窗不算点外面。**点外面即关的历史面板不能当隐藏图标后的恢复面**，也不要把面板改成常驻窗口来凑恢复入口 |
| 菜单栏图标 | **默认显示。** 右键菜单提供隐藏；隐藏后应用继续收录剪贴板。设置与独立恢复窗口提供「显示菜单栏图标」。没有恢复窗口时不得提供隐藏 |
| 隐藏图标后再次打开 | 从「应用程序」、Spotlight 或系统再次打开时，若图标已隐藏，必须把恢复窗口带到前台。**禁止**用开关历史面板来回应这次打开 |
| 恢复窗口 | 轻量、带标题栏的独立窗口：说明应用仍在运行，并提供开机自启动、检查更新、显示菜单栏图标。不是历史面板，也不是把设置窗改名 |
| 开机自启 | 提供开关，**默认关闭**。只有系统真正会在登录时拉起才算开；等待批准时开关不能显示成已开启，应引导去系统设置 › 通用 › 登录项 |
| 面板外形 | **无标题栏**；玻璃只做窗口外框，列表是内容、必须实底。默认宽 320、高 432，**不可调整大小**。列表可滚但**不显示滚动条**（接了鼠标、系统设成「滚动时显示」也不例外） |
| 上下键 | 点一下移动一条；**按住不放按系统连发速度连续移动**，预览开着同样如此，不要只动一格 |
| 快捷键默认值 | ⌘⌥V，可在设置里改 |

## 明确不做

第一波和后续默认都不做，除非产品重新拍板：

- 钉住 / 收藏
- 云同步、多设备、账号
- AI 整理、分类、改写
- 跨平台（Windows / Linux / iOS / Web）
- Mac App Store 版
- 把富文本、图片或文件降成纯文本来「凑合能搜」

## 第一波范围

第一波必须能：编译、装进「应用程序」、菜单栏出现图标、快捷键或点击图标唤出面板、Esc 或点外面立刻关闭、空格打开系统预览、⌘, 打开设置、**复制一条之后打开面板能看到这条**、**重启后 7 天内的历史还在**、回车走到粘贴接口。

第一波可以：粘贴在没有辅助功能授权时只写入系统剪贴板并提示。

第一波不要：Sparkle、GRDB、第三方热键库、网络库、SwiftData / Core Data。

## 权限降级

自动按粘贴键需要辅助功能授权。用户拒绝后，应用仍必须能把选中项写入系统剪贴板，并在面板里说明「需要到系统设置里打开，才能自动粘贴」。不得把整段功能锁死。

## 视觉

浮在桌面上的窗口边缘在 macOS 26 用通透玻璃（与同类捕捉窗同一套，不要雾面块）；**列表和搜索是同一块内容实底**，不要给搜索框单独加描边或另一套底色。文字永远在干净底上。预览交给系统 Quick Look，不要在历史面板里再做一块预览区。**禁止任何控件外圈高光方框**（系统与自绘描边一律不要）。列表选中用填充高亮，不要整行外包描边。面板没有标题栏。

菜单栏图标沿用双键帽层叠关系：前层保留 ⌘ 与完整轮廓，后层在两者交叠区域的上半部分不显示线条，只从右侧和下侧露出轮廓，避免线条穿过前层内容。
